# Sistema Musical – Back-end

## Sobre o projeto
Este projeto é a continuação da primeira fase, na qual foram desenvolvidas as telas do Sistema Musical utilizando HTML5 e CSS3.

Nesta segunda fase, o objetivo é transformar as páginas estáticas em um sistema funcional, utilizando PHP e MySQL.

## Objetivo
Desenvolver um catálogo musical que permita cadastrar, editar, excluir e visualizar artistas e músicas, além de realizar login com segurança.

## Funcionalidades
- Login com sessão e senha criptografada.
- Conexão com banco de dados MySQL.
- Cadastro, edição e exclusão de artistas.
- Cadastro, edição e exclusão de músicas.
- Upload e redimensionamento de imagens.
- Biblioteca musical com filtros de pesquisa.
- Encerramento de sessão (logout).

## Tecnologias utilizadas
- PHP
- MySQL
- HTML5
- CSS3
- XAMPP
- phpMyAdmin

## Desenvolvimento
O projeto será desenvolvido por etapas, adicionando e testando cada funcionalidade até completar o sistema.

O arquivo `styles.css` continuará sendo o mesmo utilizado na primeira fase, mantendo a identidade visual do projeto.
